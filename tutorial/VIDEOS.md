# MathCalcu Tutorial Videos

Source MP4s are too large to version in git. They live as release assets on
**v1.12.10** and are ignored in the worktree (`tutorial/*.mp4`).

- Tutorial: https://github.com/Shuash11/MathCalcu/releases/download/v1.12.10/mathcalcu_tutorial.mp4
- Promo: https://github.com/Shuash11/MathCalcu/releases/download/v1.12.10/mathcalcu_promo.mp4

To refresh: `gh release upload v1.12.10 tutorial/<file>.mp4 --clobber`.
Note: local worktree files use the `MathCalcu_` prefix (capital M, C);
release asset names are lowercase (`mathcalcu_*`).
